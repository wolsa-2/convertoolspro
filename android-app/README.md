# Toolora Android App

Native Android application for Toolora, built with Kotlin and Jetpack Compose.

## Requirements
- Android Studio with JDK 17
- Android SDK Platform 36
- Android SDK Build-Tools
- Gradle wrapper generated by Android Studio or Gradle 8.11.1

## Build a debug APK
From this directory, open the project in Android Studio and let Gradle sync. Then use **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

CLI (after installing Android SDK and creating a Gradle wrapper):
```bash
gradle assembleDebug
```

APK output:
`app/build/outputs/apk/debug/app-debug.apk`

## Current scope
The first native MVP includes a home dashboard and offline tools: text case converter, character counter, JSON formatter/validator, Base64 encoder/decoder, and a cryptographically secure password generator. All of these are processed locally on-device.

This is a separate native app; it does not modify the web app or call its APIs.
